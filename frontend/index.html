        How it is protected

        1. You sign in with Cognito; API Gateway checks your token on every request.
        2. A Lambda with least-privilege IAM hands out S3 links that expire in 5 minutes.
        3. CloudTrail records every change; EventBridge spots risky ones.
        4. A second Lambda re-locks the bucket and SNS emails an alert.
